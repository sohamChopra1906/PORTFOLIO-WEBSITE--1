# Personal Profile Webpage

## Files
- `index.html` — webpage structure and content
- `style.css` — styling and responsive layout
- `profile.svg` — temporary profile-photo placeholder

## Before submission
1. Open `index.html`.
2. Replace `Your Name`, university, school, email and other placeholder details.
3. Replace `profile.svg` with your own photograph if required.
4. Test `index.html` by opening it in a browser.
5. Upload the files to a public GitHub repository.
6. Enable GitHub Pages using the repository's `main` branch.
